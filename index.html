How it works

The pool holds one key, so one address, on both chains. Send to it on the chain you have coins on and the same amount, less the fee, arrives at your own address on the other chain, because your address is the same string there. Each swap is announced on Nostr so the pool pays within seconds, and every swap is recorded in a ledger marked on txbt4.
